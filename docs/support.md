# Support

Use the public [Flamilingo documentation repository](https://github.com/Umair-git/flamilingo-docs) to [report a problem or request a feature](https://github.com/Umair-git/flamilingo-docs/issues/new/choose). Documentation corrections are welcome there too.

When reporting a tool issue, include:

1. Your Unity version and operating system.
2. The Flamilingo page or component involved.
3. Short reproduction steps and what happened instead.
4. Relevant Console errors or a screenshot.

The Hub's **Help → Copy diagnostics** button copies the Unity version, storage choice, and translation service choice. Paste those details into an issue if they help explain the problem.

For common setup and runtime problems, check the [FAQ](faq.md) first.
